# Registre des Fonctionnalités Iroko (`docs/FEATURES.md`)

Ce registre recense chaque contrôle, vue et fonctionnalité de l'application avec son statut d'implémentation actuel, ses fichiers sources et ses critères d'acceptation. Conformément aux Règles Permanentes v2, aucun contrôle simulé n'est admis : tout contrôle est soit **Réel**, soit **Désactivé** (`disabled`, `aria-disabled="true"`, raison accessible, `cursor-not-allowed`, sans `pointer-events-none`).
